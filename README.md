## 📌 Project Overview

The **Sales Performance Analytics Dashboard** is a data analysis project designed to explore sales data, identify business trends, and understand product and regional performance.

Using Python and data visualization libraries, this project cleans and analyzes sales data to uncover useful insights that can support data-driven business decisions.

## 🎯 Project Objectives

- Analyze sales performance across product categories.
- Compare sales performance across different regions.
- Identify sales trends over time.
- Understand customer payment method preferences.
- Clean and prepare the dataset for analysis.
- Create clear visualizations to communicate findings.

## 📂 Dataset

**Dataset file:** `sales_dataset.csv`

The project uses sales transaction data for exploratory analysis.

The dataset may contain fields such as:

- `Order_ID` — Order identifier
- `Product_Category` — Product category
- `Region` — Sales region
- `Order_Status` — Current order status
- `Payment_Method` — Payment method
- `Gender` — Customer gender
- `Total_Sales` — Sales amount
- `Profit` — Profit earned

*The exact columns depend on the CSV file used in the notebook.*

## 🛠️ Technologies Used

- **Python** — Data analysis and programming
- **Pandas** — Data manipulation and cleaning
- **NumPy** — Numerical operations
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization
- **Jupyter Notebook / Google Colab** — Development environment

## 🔄 Project Workflow

1. **Data Loading:** Load the sales dataset using Pandas.
2. **Data Profiling:** Examine dataset dimensions, data types, and statistical summaries.
3. **Data Cleaning:** Handle missing values, remove exact duplicate rows, and standardize text values.
4. **Exploratory Data Analysis:** Analyze sales patterns, categories, regions, and payment methods.
5. **Data Visualization:** Create charts to communicate important patterns.
6. **Insights:** Interpret the findings and identify potential business opportunities.

## 📈 Visualizations

The project can include the following visualizations, depending on the analyses implemented in the notebook:

- **Category Revenue vs. Profit:** Compare financial performance across product categories.
- **Regional Sales Analysis:** Examine sales distribution across regions.
- **Sales Trend Analysis:** Understand how sales change over time.
- **Payment Method Analysis:** Compare the frequency of different payment methods.

## 💡 Key Learnings

- Understanding real-world data cleaning techniques.
- Performing exploratory data analysis using Pandas.
- Grouping and aggregating sales data.
- Creating meaningful charts using Matplotlib and Seaborn.
- Interpreting data patterns to communicate business insights.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Muthuvanesh/sales-performance-analytics-dashboard.git
```

### 2. Navigate to the project folder

```bash
cd sales-performance-analytics-dashboard
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Open the notebook

```bash
jupyter notebook sales_performance_analytics_dashboard.ipynb
```

Alternatively, upload the notebook and dataset to Google Colab.

### 5. Load the dataset

Ensure `sales_dataset.csv` is available at the file path specified in the notebook before running the analysis.
